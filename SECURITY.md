# Security Policy

## Reporting a Vulnerability

Please do not open a public issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting for this repository:

<https://github.com/bigdra50/unilyze/security/advisories/new>

Include the affected version, reproduction steps, impact, and any suggested mitigation.
The maintainers will acknowledge the report through the private advisory and coordinate disclosure there.

## Supported Versions

Security fixes are provided for the latest released version.
Users should upgrade to the newest NuGet package before reporting an issue that may already be fixed.

## Threat Model

The HTML viewer threat model, including analysis of untrusted repositories, is documented in [docs/threat-model.md](docs/threat-model.md).
