# UNI003: Excessive parameters

## What and why

Method has more than 5 parameters.

Many parameters increase coupling and call-site errors.

**Threshold:** parameter count > 5.

**How to fix:** introduce a parameter object, builder, or split the method.

## Default thresholds

| Severity | Condition |
|----------|-----------|
| Warning | parameter count > 5 |

## Fix guidance

Introduce a parameter object or split responsibilities (threshold: params > 5).

## Tags

`maintainability`

## Suppression

Place `// unilyze-disable UNI003 -- reason` in the leading trivia of the reported type or method declaration.
Metric findings are matched by type or method name, so suppressing one overload also suppresses same-name overloads.
For partial types, place the directive on the declaration indexed by unilyze.
For project-wide suppression, use `"rules": { "UNI003": "off" }`; use a baseline to freeze existing findings while reporting new ones.
