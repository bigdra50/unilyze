# UNI013: Implicit params array allocation

## What and why

Implicit array allocation for params parameter.

Implicit `params` arrays allocate on every call.

**How to fix:** use `Span<T>`, `ReadOnlySpan<T>`, or explicit overloads.

## Fix guidance

Replace params with Span<T>, ReadOnlySpan<T>, or explicit overloads.

## Tags

`performance`, `gc-pressure`

## Suppression

Use `// unilyze-disable-next-line UNI013 -- reason` immediately before the reported line.
These detector findings are line-based, so separate overload occurrences can be suppressed independently.
For project-wide suppression, use `"rules": { "UNI013": "off" }`; use a baseline to freeze existing findings while reporting new ones.
